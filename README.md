# Arquitectura C4 - Sistema Distribuido de Gestión de Fotografías

Repositorio de diagramas como código (**C4-PlantUML**) correspondiente al apartado 4 de la memoria de **Diseño de Sistemas de Información (MUEI - UDC)**.

## Patrones Arquitectónicos Representados
* **Client-Server & Layered Architecture**
* **Replicated Servers** (Metaservidor, Identidad y Nodos de Fotos)
* **Microkernel** (Núcleo extensible de procesamiento y formatos)
* **Subsystem Interface** (Fachadas hacia motores de almacenamiento y nubes externas)
